# ARCHITECTURE STANDARDS & MODULAR STRUCTURE RULE

## Mandatory Directives
1. **Zero Monolithic Files:** No monolithic files allowed under any circumstance.
2. **Categorical Directory Organization:** All code must be segregated by domain, layer, and service with explicit boundaries.
3. **Open-Source Readability:** Code must be structured for maximum educational, debuggability, and testability value.
4. **Single Responsibility Files:** Keep interfaces, business logic, validators, error handlers, and unit tests in distinct, dedicated files within each service folder.
